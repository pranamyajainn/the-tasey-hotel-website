# The Tasey - Luxury Boutique Hotel & Restaurant 🏔️🏰

Welcome to the official repository for **The Tasey**, a lavish boutique hotel and restaurant single-page web application located near Amber Fort, Jaipur, nestled in the scenic Aravali Hills.

## 🏨 About The Tasey
Located just 100 meters from Taj Amber & Indiana Place, 50 meters from Nahargarh Zoological Park, and 5 km from historic Amber Fort, **The Tasey** offers royal Rajasthani hospitality with serene hill views.

### Highlights & Key Features
- **Editorial Design System**: Magazine-style typography, warm ivory palette (`#FAF8F5`), gold accents (`#C5A880`), and custom arched imagery frame viewports.
- **Luxurious Accommodations**: Showcasing Luxury Rooms, Executive Rooms, and Royal Suites with interactive booking modal.
- **Signature Dining**:
  - *Haldi*: Traditional indoor Rajasthani & Indian dining experience.
  - *Jhumka*: Panoramic rooftop pool restaurant overlooking the Aravali Hills.
- **Banquets & Celebrations**: Two grand banquet halls for weddings, corporate events, and parties.
- **Jaipur Attractions Showcase**: Interactive visual photography cards for nearby sights (Amber Fort, Jal Mahal, Nahargarh).
- **Instant WhatsApp Booking & Inquiry**: Floating direct action button for rapid mobile guest inquiries.

---

## 🛠️ Technology Stack
- **Framework**: [Next.js 15+ (App Router)](https://nextjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) + Custom Design Tokens (`globals.css`)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)

---

## 🚀 Getting Started

First, install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

---

## 📦 Deployment

This project is optimized for deployment on **[Vercel](https://vercel.com/)**.

To deploy manually via Vercel CLI:
```bash
npx vercel
```
